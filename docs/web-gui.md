# 网页界面

单页应用，入口 `http://<本机IP>:8765/`。两个模块共用一个外壳：

- **图库（灵感库）**：AI 生成的效果图 + 拆解 + 提示词，可原地改提示词、用自己的模型 Key 直接生图。
- **老房改造**：列表优先的项目管理，原图 → 改造效果图，每次生成是一个独立版本。

仓库自带示例数据（10 张图库 + 5 个改造项目），首次启动自动导入；
其余图片由用户用自己的模型 Key 生成。

顶部导航切换，右上「设置」管理模型凭据（见 `credentials.md`）。
尚未配置 Key 时，页面顶部会出现提示条「还没配置模型 Key，点右上「设置」填一个」；
配置后徽章显示 `本地 Key` 或 `环境变量`。

## 图库

### 列表

分类筛选 + 卡片网格。点卡片进详情。缩略图由 `/thumbs/<id>.jpg` 现生成、缓存
480 px 宽，列表里懒加载。

### 详情（区块顺序）

```text
主图 → 生成结果 → 条目信息 → 空间色板 → 空间拆解 → 提示词 → 生成新图
```

- **主图是 AI 生成的效果图**：`local_path` 指向 `images/ai/<分类>/<id>.webp`；
  示例图随仓库提供，新图由用户用自己的模型 Key 生成。
- 条目信息最后一行是 **图像来源 = AI 生成**。

- **生成结果在主图正下方**：最新一张排最左，带「最新」角标；超过 4 张时区块最高
  320 px、内部滚动，不把下面的内容顶太远。
- 生成完成时：右上 toast `生成完成 · 用时 X 分 Y 秒`、新卡片平滑滚动到视野中间、
  闪 2 秒橙色描边、状态行 `aria-live` 播报。失败则是错误 toast + 滚到状态行。
- 提示词、尺寸、负面词都在详情里可改，改动会写回该条目（可 `restore` 还原）。
- 「查看对比」打开参考图 / 生成图并排弹窗。

## 老房改造

### 列表页

三列卡片，每张卡：封面缩略图、名称、风格、版本数、更新时间、`⋯` 菜单
（重命名 / 换封面 / 删除）。右上「新建改造项目」。

### 新建弹窗

- 选图后**立即显示预览**（`object-fit: cover`），并保留「文件名 · 大小」一行。
- 支持拖拽入框、点击虚线框重选、底部「重新选择 / 移除」。
- 客户端校验：JPEG / PNG / WebP，≤ 12 MB；不合格直接提示，不提交。
- 项目名可留空，默认「空间 · 风格」，如「客厅 · 北欧」。

### 详情页

```text
左：原图（可换） | 右：结构分析 · 生成参数 · 最新结果 · 版本历史
```

- **结构分析**：`不可改结构` / `可替换软装` 两块。有分析时显示 AI 逐项结论；
  没有分析时显示占位文案，旁边「分析结构」按钮可随时补跑。
- **生成参数**：模式（图生图 / 纯文本）、风格包、尺寸、备注。
- **添加细节（可选）**：勾选后模型会在现有家具/台面上补充绿植、挂画、织物、摆件等小型装饰，
  不改变建筑结构；下方文本框可填想要的细节（最多 300 字，未勾选时禁用），生成成功后自动清空并取消勾选。
  历史版本中带此选项的会显示「含细节」标签。
- **最新结果**：封面版本或最新成功版本，标注分数、耗时、尺寸。
- **细节优化**：在「当前结果」卡片底部的操作排（与「下载成品 / 下载原图 / 对比原图」同一行）。
  前置条件是项目至少有一个结果版本；没有结果时按钮禁用，悬停提示「先生成一次改造结果」。
  点按钮展开内联面板，可填最多 300 字的装饰细节（例如绿植、挂画、叠搭地毯），
  点「开始优化」后以**当前结果图**为 img2img 输入，只增加小型装饰，不改结构、家具、机位与比例。
  生成的是**追加的新版本**，不会覆盖旧结果；完成后面板收起并清空，toast 提示「细节优化完成」。
  版本历史中该版本带「含细节」与「由结果优化」标签。
- **版本历史**：每次生成一张卡，按时间倒序；卡上可看分数、尝试次数、失败原因，
  可改备注、设为封面、删除单版、点开大图。
- 生成完成时同样有 toast；若你还在页面顶部（`scrollTop ≤ 160`）会自动滚到最新结果，
  已经翻到历史区就只提示、不抢位置。

### 分析策略（重要）

| 模式 | 是否要求先分析 | 说明 |
| --- | --- | --- |
| 图生图（默认） | **不要求** | 直接生成。提示词里仍有硬指令锁墙线、洞口、层高、机位、比例 |
| 纯文本 | 要求 | 没分析时任务先跑 `analyzing`，再生成；分析失败给明确中文错误 |

所以新建项目不再自动分析，创建即可用。有分析结果的项目，图生图会把逐项结构
（洞口在哪面墙、多宽、固定构件清单）一并写进提示词，锁得更细。

### 图片放大（灯箱）

- 可点：原图、最新结果、版本历史缩略图、图库详情里的图。
- 不可点：**列表页卡片缩略图**（点它是进详情）、新建弹窗里的预览（点它是重选）。
- 交互：点图在「适应屏幕 ↔ 1:1」之间切换，1:1 可拖拽平移；`←`/`→` 翻页、
  `Esc` 关闭、点背景关闭；右上关闭按钮、右下下载。
- 关闭后焦点回到刚才那张图。

## 键盘与可访问性

| 键 | 作用 |
| --- | --- |
| `Esc` | 关闭灯箱 / 弹窗 |
| `←` / `→` | 灯箱上一张 / 下一张 |
| `Tab` | 弹窗内焦点循环 |

灯箱与弹窗都有 `aria-label`、焦点回收，状态变化走 `aria-live`；
`role="dialog"` / `aria-modal` 尚未补（已知缺口）。

## 已知限制

- 无鉴权：同一 WiFi 下任何人都能打开并消耗生图额度。
- 生成图是**改造效果图**，不是实拍：地板铺装偶发被人字拼替换、灯具会有光晕、
  窗景偏干净。自查分数只作趋势参考，不当质量背书。
- 图生图单张 163–271 秒，触发自动修复可到 410 秒；纯文本 120–170 秒。
- 提示词改完要等下一次生成才生效，不会自动重生成。
- 列表缩略图缺失时按需生成，首次进列表可能稍慢（之后走缓存）。
